# Mzda (net salary calculator) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Czech gross-to-net salary calculator tab, **Mzda** (EN "Salary"), at `/mzda`. Dashboard can take its net figure as income. New visitors get Czech and CZK by default.

**Architecture:** A pure rules module, `src/lib/salary.ts`, holds the 2026 table and `calcSalary()`, and is tested with Vitest. The route `src/routes/mzda.tsx` renders inputs and results through the existing `useScenario`, `Panel` and `NumberSlider`. Dashboard reads `finbuddy.salary` from localStorage and offers a one-click "Use". The Mzda page has no button that writes to Dashboard.

**Tech Stack:** TanStack Start/Router (file routes), React 19, TypeScript (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Tailwind 4, Radix/shadcn UI, Vitest (new, dev-only).

**Spec:** `docs/superpowers/specs/2026-10-14-mzda-net-salary-design.md`

## Global Constraints

- All money on Mzda is **Kč**, whatever the app currency. Never use `useFormatters()` or `useCurrencyScale()` on Mzda. Use `formatCzk()`.
- 2026 values, verbatim from the spec. Employee 7.1 % social and 4.5 % health. Employer 24.8 % social and 9 % health. Tax 15 %, plus 23 % on the monthly base above **146,901 Kč**. Social cap **2,350,416 Kč**/year. Payer credit **2,570**. Disability **210 / 420**, ZTP/P **1,345**. Child benefit **1,267 / 1,860 / 2,320**, doubled for ZTP/P. Minimum wage **22,400** (bonus threshold 11,200).
- Rounding: insurance rounded **up** to whole crowns; tax base rounded **up** to whole hundreds; tax rounded **up** to whole crowns.
- Storage key: `finbuddy.salary`. Route path `/mzda`. Tab label key `"Salary"`, Czech `"Mzda"`.
- Every user-visible string goes through `t()` from `useT()`, with a Czech entry in `CS` in `src/lib/i18n.tsx`. Keys are English source text.
- **Do not push.** Pushing `main` syncs to Lovable. Commit locally only, and never amend or rebase commits that are already pushed (see `AGENTS.md`).
- `npm run lint` already reports ~200 errors in untouched files, mostly formatting. Don't fix them. Run `npx eslint <files you touched>` and `npx prettier --write <files you touched>` instead.
- Type check with `npx tsc --noEmit`. It passes today and must still pass after every task.
- `bun` is not installed locally, so `bun.lock` can't be updated. Use `npm`, and leave `bun.lock` alone.

## Review Focus

1. **Floating-point off-by-one crowns.** `40000 * 0.071` is `2840.0000000000005` in JS, so `Math.ceil` returns 2841. All percentages must use whole-number basis points on whole crowns. Pinned by the exact-net tests in Task 1, plus a sweep test over many salaries.
2. **Bad values from shared URLs or storage.** A hand-edited URL such as `?kids=9&kidsZtp=12&gross=-5&disability=2` must not crash or produce nonsense. Expect clamping to sane values. Pinned by `normalizeInput` tests in Task 1.
3. **Bonus threshold boundary.** Exactly 11,200 Kč must pay the bonus, and 11,199 must not. Pinned in Task 1.
4. **Corrupt `finbuddy.salary` in localStorage**, such as invalid JSON or an array. Dashboard must still render, showing the "Calculate from gross" link. Pinned by `parseSalaryStore` tests in Task 1.
5. **Returning users keep their saved language and currency** after the defaults switch to cs/CZK. Checked manually in the browser in Task 5.

```ts
/**
 * Czech gross → net salary for employees on a standard contract (HPP), per month.
 * Pure: no React, no browser APIs. Rates are basis points so maths on whole crowns
 * stays exact (40,000 × 0.071 is 2840.0000000000005 in floating point).
 */

export type Disability = 0 | 1 | 3;

export type SalaryInput = {
  /** Monthly gross, whole Kč. */
  gross: number;
  /** "Prohlášení poplatníka" signed — required for credits and child benefit. */
  signed: boolean;
  kids: number;
  /** How many of `kids` hold a ZTP/P card (≤ kids). */
  kidsZtp: number;
  /** 0 none, 1 = degree I–II, 3 = degree III. */
  disability: Disability;
  /** Employee holds a ZTP/P card. */
  ztp: boolean;
};

/** Loose input as it arrives from URL params or localStorage. */
export type SalaryDraft = { [K in keyof SalaryInput]?: unknown };

export type SalaryRules = {
  year: number;
  employeeSocialBp: number;
  employeeHealthBp: number;
  employerSocialBp: number;
  employerHealthBp: number;
  taxBp: number;
  highTaxBp: number;
  /** Monthly tax base above which `highTaxBp` applies (36 × average wage / 12). */
  highTaxThreshold: number;
  /** Annual social insurance cap (48 × average wage). */
  socialCapYearly: number;
  payerCredit: number;
  disabilityCredit: { 1: number; 3: number };
  ztpCredit: number;
  /** Monthly benefit for the 1st, 2nd, and 3rd-and-later child. */
  childBenefit: readonly [number, number, number];
  minWage: number;
};

export const CZ_2026: SalaryRules = {
  year: 2026,
  employeeSocialBp: 710,
  employeeHealthBp: 450,
  employerSocialBp: 2480,
  employerHealthBp: 900,
  taxBp: 1500,
  highTaxBp: 2300,
  highTaxThreshold: 146901,
  socialCapYearly: 2350416,
  payerCredit: 2570,
  disabilityCredit: { 1: 210, 3: 420 },
  ztpCredit: 1345,
  childBenefit: [1267, 1860, 2320],
  minWage: 22400,
};

export type SalaryResult = {
  gross: number;
  social: number;
  health: number;
  taxBase: number;
  taxBeforeCredits: number;
  credits: { payer: number; disability: number; ztp: number };
  taxAfterCredits: number;
  childBenefit: { total: number; reducesTax: number; bonus: number };
  /** Final monthly tax advance, ≥ 0. */
  tax: number;
  net: number;
  employerSocial: number;
  employerHealth: number;
  employerCost: number;
  /** Yearly gross exceeds the social cap; the cap is annual so it isn't applied here. */
  aboveSocialCap: boolean;
};

export const SALARY_KEY = "finbuddy.salary";

export const SALARY_DEFAULTS: {
  gross: number;
  signed: boolean;
  kids: number;
  kidsZtp: number;
  disability: number;
  ztp: boolean;
} = { gross: 48967, signed: true, kids: 0, kidsZtp: 0, disability: 0, ztp: false };

const MAX_KIDS = 6;

const toNum = (v: unknown) => {
  const n = typeof v === "number" ? v : typeof v === "string" ? parseFloat(v) : NaN;
  return Number.isFinite(n) ? n : 0;
};

const clamp = (n: number, min: number, max: number) => Math.min(max, Math.max(min, n));

/** `amount` × basis points, rounded up to whole crowns. */
const pctUp = (amount: number, bp: number) => Math.ceil((amount * bp) / 10000);

export function normalizeInput(raw: SalaryDraft): SalaryInput {
  const gross = Math.max(0, Math.round(toNum(raw.gross)));
  const kids = clamp(Math.round(toNum(raw.kids)), 0, MAX_KIDS);
  const kidsZtp = clamp(Math.round(toNum(raw.kidsZtp)), 0, kids);
  const d = Math.round(toNum(raw.disability));
  const disability: Disability = d === 1 || d === 3 ? d : 0;
  return { gross, signed: raw.signed !== false, kids, kidsZtp, disability, ztp: raw.ztp === true };
}

/** ZTP/P children take the highest-order slots (largest benefit), which parents may choose. */
function childBenefitTotal(kids: number, kidsZtp: number, rules: SalaryRules) {
  let total = 0;
  for (let i = 0; i < kids; i++) {
    const amount = rules.childBenefit[Math.min(i, 2)] ?? 0;
    total += i >= kids - kidsZtp ? amount * 2 : amount;
  }
  return total;
}

export function calcSalary(input: SalaryDraft, rules: SalaryRules = CZ_2026): SalaryResult {
  const { gross, signed, kids, kidsZtp, disability, ztp } = normalizeInput(input);

  const social = pctUp(gross, rules.employeeSocialBp);
  const health = pctUp(gross, rules.employeeHealthBp);

  const taxBase = Math.ceil(gross / 100) * 100;
  const low = Math.min(taxBase, rules.highTaxThreshold);
  const high = Math.max(0, taxBase - rules.highTaxThreshold);
  const taxBeforeCredits = Math.ceil((low * rules.taxBp + high * rules.highTaxBp) / 10000);

  const credits = signed
    ? {
        payer: rules.payerCredit,
        disability: disability === 0 ? 0 : rules.disabilityCredit[disability],
        ztp: ztp ? rules.ztpCredit : 0,
      }
    : { payer: 0, disability: 0, ztp: 0 };
  const taxAfterCredits = Math.max(
    0,
    taxBeforeCredits - credits.payer - credits.disability - credits.ztp,
  );

  const total = signed ? childBenefitTotal(kids, kidsZtp, rules) : 0;
  const reducesTax = Math.min(total, taxAfterCredits);
  const bonus = gross >= rules.minWage / 2 ? total - reducesTax : 0;
  const tax = taxAfterCredits - reducesTax;

  const employerSocial = pctUp(gross, rules.employerSocialBp);
  const employerHealth = pctUp(gross, rules.employerHealthBp);

  return {
    gross,
    social,
    health,
    taxBase,
    taxBeforeCredits,
    credits,
    taxAfterCredits,
    childBenefit: { total, reducesTax, bonus },
    tax,
    net: gross - social - health - tax + bonus,
    employerSocial,
    employerHealth,
    employerCost: gross + employerSocial + employerHealth,
    aboveSocialCap: gross * 12 > rules.socialCapYearly,
  };
}

/** Reads the Mzda tab's saved scenario (localStorage JSON). Null if absent or unusable. */
export function parseSalaryStore(raw: string | null): SalaryInput | null {
  if (!raw) return null;
  try {
    const parsed: unknown = JSON.parse(raw);
    if (!parsed || typeof parsed !== "object" || Array.isArray(parsed)) return null;
    return normalizeInput(parsed as SalaryDraft);
  } catch {
    return null;
  }
}

const czk = new Intl.NumberFormat("cs-CZ", {
  style: "currency",
  currency: "CZK",
  maximumFractionDigits: 0,
});

/** Always Kč, independent of the app currency. */
export const formatCzk = (value: number) => czk.format(isFinite(value) ? value : 0);
```

```tsx
  if (r.childBenefit.total) rows.push({ label: t("Child benefit"), value: r.childBenefit.total });
  rows.push({ label: t("Income tax"), value: -r.tax });
  if (r.childBenefit.bonus) rows.push({ label: t("Child bonus"), value: r.childBenefit.bonus });
  rows.push({ label: t("Net salary"), value: r.net, strong: true });

  const bonusThreshold = CZ_2026.minWage / 2;

  return (

      <div className="lg:sticky lg:top-32 lg:self-start">
        <Panel className="space-y-6">
          <NumberSlider
            label={t("Gross monthly salary")}
            value={s.gross}
            onChange={(v) => patch({ gross: Math.round(v) })}
            min={0}
            max={300000}
            step={500}

                max={s.kids}
```
